WORKSPACE 01 / MEMBER SIDE

User Panel

Pages and logic available to a registered matrimonial member.

12 MODULES
Core ruleA user can view public/allowed profile information, but private contact details and protected photos must be returned only after server-side permission checks.
U01Entry

Home / Landing Page

Public introduction and entry point for new visitors.

  • Show platform introduction, benefits and membership highlights.
  • Show featured or success-story profiles only with consent.
  • Buttons for Register, Login and Browse public content.
  • Do not expose private member data in public pages or search indexing.
U02Authentication

Register & Login

Create and securely access a member account.

  • Register with name, email/mobile, password and basic consent.
  • Verify email/mobile using OTP before activating the account.
  • Login, logout, forgot password and reset password flows.
  • Rate-limit OTP/login attempts; hash passwords and rotate refresh tokens.
  • Block suspended or deleted accounts from creating sessions.
U03Onboarding

Create My Profile

Collect the member's matrimonial biodata in guided steps.

  • Personal, family, education, profession and lifestyle details.
  • Religion, community, mother tongue and location where applicable.
  • Upload profile photo and optional gallery/documents.
  • Save draft, validate required fields and show completion percentage.
  • Set visibility and consent preferences before publishing.
U04Profile

My Profile & Edit

View and maintain the member's own profile.

  • Show profile preview, completion status and verification badges.
  • Edit fields with validation and keep a change history for sensitive edits.
  • Submit selected changes for admin re-approval if required.
  • Allow photo replacement, removal and privacy controls.
  • Pause profile, deactivate account or request account deletion.
U05Preferences

Partner Preference

Define what kind of partner the member is looking for.

  • Age range, height, marital status and location range.
  • Education, occupation, income and lifestyle preferences.
  • Religion/community preferences only where the platform supports them.
  • Support must-have and flexible preferences separately.
  • Validate ranges and use preferences in matching/search APIs.
U06Discovery

Search & Browse Profiles

Find relevant profiles with controlled filters.

  • Keyword, age, location, education, profession and other filters.
  • Sorting, pagination and saved searches.
  • Exclude own profile, blocked users, hidden and suspended profiles.
  • Apply membership limits and profile visibility rules on the server.
  • Return only fields the viewer is authorised to see.
U07Discovery

Profile Details

Show a detailed view of another member's profile.

  • Display biodata sections according to the owner's privacy settings.
  • Mask phone, email and exact address by default.
  • Protect private photos with expiring/authorised access links.
  • Show verification status and report/block actions.
  • Record profile views according to the platform's privacy policy.
U08Engagement

Interest & Requests

Manage proposal and contact requests between members.

  • Send, accept, reject, withdraw and cancel an interest request.
  • Prevent duplicate requests and requests to blocked members.
  • Show sent, received, accepted and declined request lists.
  • Unlock contact only after mutual acceptance and plan permission.
  • Notify both parties when request status changes.
U09Engagement

Shortlist & Block List

Let members organise profiles and control unwanted contact.

  • Add/remove profiles from shortlist or favourites.
  • Maintain a private personal shortlist.
  • Block/unblock members and prevent future interactions.
  • Apply block rules to search, profile views, chat and requests.
U10Communication

Chat & Notifications

Communicate after the platform's eligibility rules are met.

  • Enable chat only for accepted/mutual connections or eligible plans.
  • Real-time messages, unread count and conversation history.
  • Block/report from conversation; restrict attachments and spam.
  • In-app notifications for interests, matches and account activity.
  • Email/WhatsApp notifications only with consent and configured providers.
U11Billing

Membership & Payments

Purchase plans and view membership entitlements.

  • Show plan price, duration, benefits and usage limits.
  • Create payment order on backend; verify signed gateway response/webhook.
  • Activate benefits only after verified payment confirmation.
  • Show invoices, transaction history, expiry and renewal options.
  • Never trust a payment-success redirect from the browser alone.
U12Support

Settings, Help & Safety

Give members control over account and safety actions.

  • Manage password, contact verification and notification preferences.
  • Control profile/photo/contact visibility.
  • Submit complaints, report fake profiles and request support.
  • View terms, privacy policy, consent history and account deletion options.
  • Show safety guidance and emergency reporting route.
WORKSPACE 02 / CONTROL SIDE

Admin Panel

Pages and logic used by authorised platform administrators.

12 MODULES
Core ruleAdmin actions must be protected by role-based permissions, server-side checks and an audit log. A hidden button is not access control.
A01Access

Admin Login

Secure entry for staff and administrators.

  • Separate admin authentication route and session policy.
  • Support MFA for privileged accounts.
  • Apply role/permission checks on every admin API.
  • Rate-limit login and record suspicious access attempts.
  • Never create a public admin registration endpoint.
A02Overview

Dashboard & Analytics

Show a quick operational summary of the platform.

  • Total, active, pending, suspended and deleted members.
  • New registrations, profile completion and verification queue.
  • Membership sales, successful payments, refunds and revenue.
  • Charts by date, plan and registration source.
  • Use date filters and permission-aware aggregate APIs.
A03Members

Manage Members

Search and manage user accounts.

  • Search by member ID, name, email/mobile and status.
  • View account/profile summary and verification history.
  • Activate, suspend or restrict accounts with a reason.
  • Admin edits to sensitive fields must be logged.
  • Export only permitted fields with export audit records.
A04Moderation

Profile Approval

Review new profiles and changes before publication.

  • Queues for new profiles, edited profiles and photos.
  • Approve, reject or request correction with a reason.
  • Check suspicious/duplicate profiles and prohibited content.
  • Keep reviewer, timestamp and decision history.
  • Only approved profiles become discoverable where required.
A05Verification

Verification Centre

Review member verification evidence.

  • Track mobile/email verification separately from identity checks.
  • Review submitted documents only when necessary and lawful.
  • Approve/reject with reason and expiry/re-verification rules.
  • Restrict document access to specifically authorised staff.
  • Record every view, download and status change.
A06Plans

Membership Plans

Configure plans and their feature entitlements.

  • Create/edit plans, price, validity and display order.
  • Set limits for contact unlocks, interests, chats and visibility.
  • Enable/disable plans without corrupting existing subscriptions.
  • Version plan benefits so old purchases retain their terms.
  • Define trial, coupon and renewal rules if required.
A07Finance

Payments & Transactions

Track money movement and resolve payment issues.

  • View orders, gateway references, payment status and invoices.
  • Process refunds through supported gateway workflow.
  • Handle failed, pending, duplicate and webhook-retry cases.
  • Reconcile gateway reports with internal transaction records.
  • Never edit payment status without an auditable reason.
A08Safety

Reports & Complaints

Handle member reports and platform abuse.

  • Queue reports for fake profile, harassment, spam or fraud.
  • View relevant evidence with restricted access.
  • Assign cases, add internal notes and set resolution status.
  • Warn, restrict or suspend accounts according to policy.
  • Track resolution time and repeat offenders.
A09Content

Website Content

Manage public information without code changes.

  • Edit banners, FAQs, success stories and static pages.
  • Manage testimonials only with documented consent.
  • Set SEO title, description and social sharing metadata.
  • Preview and publish content with author and publish history.
A10Operations

Notifications & Templates

Control transactional communication.

  • Manage email, SMS and WhatsApp message templates.
  • Configure provider credentials in secure server-side secrets.
  • View delivery status, retries and provider error logs.
  • Respect opt-in, opt-out and communication preferences.
  • Do not expose API keys or SMTP passwords in frontend responses.
A11Staff

Admin Users & Roles

Give staff only the access they need.

  • Create staff accounts and assign granular permissions.
  • Separate super admin, moderator, support and finance roles.
  • Allow permission changes and immediate session revocation.
  • Log login, data access, exports and sensitive actions.
A12Configuration

Settings & Audit Logs

Manage platform rules and trace important actions.

  • Configure platform name, contact details and feature switches.
  • Set profile approval, privacy defaults and retention policies.
  • Maintain audit logs for admin and system-level changes.
  • Manage backups, data export and incident response procedures.
  • Keep secrets in environment/secret manager, never in source code.
APPLIES TO BOTH PANELS

Shared system rules

These rules belong in backend services and database design—not just in page-level UI.

01

Authentication & Permissions

Secure sessions, password hashing, OTP throttling, role-based access and server-side authorisation.

02

Privacy by Default

Minimise personal data, mask contact details, protect private media and record consent/preferences.

03

Data & API Validation

Validate every request on the server, use pagination, indexes, safe file uploads and consistent API errors.

04

Audit & Reliability

Track sensitive actions, handle payment webhooks idempotently, back up data and monitor failures.

IMPLEMENTATION ORDER

Recommended coding sequence

Build and test one complete flow at a time. Do not start all modules simultaneously.

  1. FoundationProject setup, database, environment config, logging and API structure.
  2. AuthenticationMember/admin login, OTP, sessions, roles and permissions.
  3. Member CoreRegistration, biodata, profile editing and partner preferences.
  4. DiscoverySearch, profile details, shortlist, interests and block/report.
  5. Admin OperationsDashboard, member management, approvals and verification.
  6. BusinessPlans, payments, invoices, notifications and support.
  7. AdvancedChat, smart matching, horoscope and other optional capabilities.
  8. Launch ReadinessSecurity tests, privacy review, backups, monitoring and deployment.
